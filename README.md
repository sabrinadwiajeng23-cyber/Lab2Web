# Lab2Web

## Materi Praktikum

Materi yang dikerjakan meliputi:

1. Membuat tabel data mahasiswa.
2. Menggunakan thead, tbody, dan tfoot.
3. Menggunakan colspan.
4. Membuat form registrasi mahasiswa.
5. Menggunakan radio button.
6. Menggunakan checkbox.
7. Menggunakan select.
8. Menggunakan textarea.
9. Membuat validasi form.
10. Menggunakan semantic HTML.
11. Menambahkan multimedia audio dan video.
12. Membuat proyek mini biodata mahasiswa.
