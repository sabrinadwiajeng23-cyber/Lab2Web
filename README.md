## Deskripsi

Praktikum ini membahas dasar-dasar HTML lanjutan yang digunakan untuk membuat halaman web yang terstruktur dan interaktif.

Materi yang dipelajari meliputi:

- Tabel HTML
- `thead`, `tbody`, dan `tfoot`
- `colspan`
- Form HTML
- Input text
- Input email
- Input password
- Input tanggal
- Radio button
- Checkbox
- Select
- Textarea
- Validasi form
- Semantic HTML
- Audio
- Video
- Proyek mini biodata mahasiswa

---

## Tujuan Praktikum

Tujuan dari praktikum ini adalah:

1. Memahami penggunaan tabel pada HTML.
2. Memahami penggunaan form dan berbagai jenis input.
3. Memahami penggunaan radio button dan checkbox.
4. Memahami penggunaan select dan textarea.
5. Memahami validasi form menggunakan atribut HTML.
6. Memahami struktur semantic HTML.
7. Memahami penggunaan multimedia audio dan video.
8. Membuat halaman biodata mahasiswa menggunakan HTML.
